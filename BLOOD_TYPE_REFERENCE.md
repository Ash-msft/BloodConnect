# Blood Type Compatibility Reference Guide

## 🩸 Blood Type Compatibility Matrix

This is an **informational reference only**. Real-world compatibility decisions must always be confirmed by a licensed blood donation center. The blood donation center's on-site medical assessment and local regulations always take precedence.

---

## Who Can Donate to Whom?

### Universal Donor: **O-** (Negative)
Can donate to **ALL blood types**
- O-, O+, A-, A+, B-, B+, AB-, AB+

### Frequent Donors: **O+** (Positive)
Can donate to **All Positive types**
- O+, A+, B+, AB+

### Common Donor: **A+** (Positive)
Can donate to **A+ and AB+**
- A+, AB+

### Common Donor: **B+** (Positive)
Can donate to **B+ and AB+**
- B+, AB+

### Rare Donor: **AB+** (Universal Recipient)
Can receive from **ALL blood types**
- Can only donate to AB+
- Recipient for all types

### Rare Donor: **AB-** (Rh Negative Universal Recipient)
Can receive from **All Negative types**
- O-, A-, B-, AB-
- Can only donate to AB-, AB+

### Donor: **A-** (Negative)
Can donate to **A- and A+ and AB- and AB+**
- A-, A+, AB-, AB+

### Donor: **B-** (Negative)
Can donate to **B- and B+ and AB- and AB+**
- B-, B+, AB-, AB+

## Key Rules

### ABO System
- **O**: Universal donor (can donate to all ABO types)
- **A**: Can donate to A and AB
- **B**: Can donate to B and AB
- **AB**: Can only donate to AB (but can receive from all)

### Rh System
- **Negative (-)**: Can safely donate to both negative and positive recipients
- **Positive (+)**: Can only donate to positive recipients (but can receive from both)

---

## Clinical Importance

✅ **Negative donors are precious** — they're the only ones safe for Rh-negative recipients  
✅ **O-negative is the most versatile** — can go to anyone  
✅ **AB-positive can receive from anyone** — universal recipients  
❌ **Cross-Rh cannot donate** — positive cannot donate to negative (except O+ can't donate to O-)

## For BloodConnect Matching

When a request comes in for **recipient blood group X**:

1. **Identify compatible donor groups** using the matrix above
2. **Filter donors**:
   - Blood group must be in compatible list
   - Donor must be Available
   - Donor must be Eligible (56+ days since last donation)
   - Donor must be in target location (pincode-based)
3. **Prioritize by**:
   - Proximity (closest pincode first)
   - Urgency level (high/critical = fastest available)
   - Availability history (frequent donors ranked higher)
4. **Notify** only the top candidates (max 5-10 based on urgency)
